# Avian gene tree simulations used to test Phlag
## Scripts
### `concat_sequences.py`
Concatenates FASTA sequences by mixing null and alt/anomalous sequence files based on a pattern string (e.g. `nanan`).

**Usage:**
```bash
python scripts/concat_sequences.py -n <null.fa> -a <alt.fa> -p <pattern> [-o <output.fa>]
```
or using positional arguments:
```bash
python scripts/concat_sequences.py <null.fa> <alt.fa> <pattern>
```

### `generate_mapping.py`
Generates a 4-taxon population mapping TSV file (`P1`, `P2`, `P3`, `Po`) for `dstar` based on an internal node label in a species tree.

**Usage:**
```bash
python scripts/generate_mapping.py -t <species_tree.nwk> -n <internal_node> [-o <output_mapping.tsv>]
```

## Output Directory Configuration (`.env`)
By default, output files generated by the scripts are saved inside a `data/` directory located at the repository root.

You can customize the base output directory by creating a `.env` file in the root of the repository (or parent directories) and defining the `PHLAG_DIR` environment variable:

```env
PHLAG_DIR=/path/to/custom/output_directory
```

Alternatively, you can set the `PHLAG_DIR` environment variable directly in your environment before running the scripts:

```bash
export PHLAG_DIR=/path/to/custom/output_directory
```
